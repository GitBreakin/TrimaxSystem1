# Report samples (test data)

Written by the Desktop's own export code (Analytics & Reports > Export) from the **test data** used for
the Stage G screenshots, not from the live database. They show the layout every export has: the period
(Asia/Manila, both dates included), who generated it and when, the definitions, the table and the totals.

- `trimax-bookings-per-week_...csv`: Trend tab, grouped by week.
- `trimax-bookings-per-driver_...csv`: Drivers tab (counts and average start-to-delivered time; not a ranking).
- `trimax-exceptions_...csv`: Exceptions tab (SOS / problem reports, alerts not resolved, failed deliveries).

Excel and PDF exports contain the same rows.
